# MovieBook - BookMyShow-style JavaScript project

This is an educational frontend clone inspired by common movie-ticket booking flows. It is not affiliated with BookMyShow.

## Run
Open `index.html` in a browser. For the smoothest experience, use VS Code Live Server.

## Main flow
Home -> Movie -> Show time -> Theatre -> Seats -> Payment -> Booking confirmation -> My Bookings

## Technologies
HTML5, CSS3, Vanilla JavaScript.

## Data
Movies, theatres and payment are demo/local data. Bookings are stored in browser localStorage.

## Production upgrades
Add a Java/Spring Boot backend, MySQL database, real authentication, real theatre/show APIs, server-side seat locking, payment gateway, admin panel, email/SMS notifications, and secure server-side validation.
